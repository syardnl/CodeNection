MEND — Ideation Evolution Mindmap

Not a static idea list — this shows how each core mechanic actually changed shape over the build, and why. Struck-through nodes were dropped; highlighted nodes are what we kept.
Branch 1 — Onboarding Personalization

Clinical label grouping

"Which group are you: stress / ADHD / depression?" — felt like a clinical intake form, no clinical basis to back it.

→

Behavior-pattern question

"When things pile up, what usually happens to you?" — same personalization goal, no labeling. Inspired by Unstuck's pattern-awareness.

CHOSEN · REAL
Branch 2 — The Companion / Pet Concept

Normal pet-care loop

Am & Sofea's original idea — feed/water/interact with a virtual pet, separate from the app's actual data.

→

Mirror Pet

Direct response to Faris's "what's your USP?" challenge. No care actions — pet's expression IS the user's capacity/burnout state, live.

CHOSEN · REAL Faris Imran
Branch 3 — Check-in Input Method

Emoji/slider only

Original Ground Truth spec — 🙁😰😐 taps for energy/sleep/stress/focus.

→

+ Vent/free-text path

Added AI extraction as a second path — closer to how people actually vent (ChatGPT-style habit), Gemini extracts the same signals.

→

"What are we feeling today?" + SVG icons

Emoji dropped entirely for design consistency (no emoji anywhere in UI). Free-text path kept, reframed away from "journal" per Varsha.

CHOSEN · REAL Varsha
Branch 4 — Retention Mechanic

Streaks / badges

Common pattern in productivity apps — explicitly rejected early as feeling gamified and shallow.

→

Mirror Pet + Future You

Retention comes from emotional stakes (seeing your own state reflected) and consequence visibility (tomorrow's capacity), not points.

CHOSEN · REAL Faris Imran
Branch 5 — AI Safety Boundary

Vent/check-in with AI extraction

User can freely describe how their day is going — risk: could drift into "AI as therapist" territory.

→

Strict LLM boundary + crisis banner

AI framed only as "a place to say what happened." Severe distress language triggers a hardcoded (non-LLM-judgment) banner to real helplines.

CHOSEN · REAL Varsha
Branch 6 — Schedule Input (Future Direction)

Real calendar OAuth

Dropped for this build — auth/integration risk not worth absorbing in a 3-week window.

→

Mocked calendar + manual/photo entry

What we actually built — seeded calendar for demo, manual grid or photo/PDF upload otherwise.
